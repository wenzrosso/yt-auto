Privacy Policy

Last updated: October 14, 2026

What yt-auto is

yt-auto is a personal automation tool operated by a single individual (the developer). It generates videos and uploads them to the developer's own YouTube channel. It is not offered to the public and has no other users.

Google user data the app accesses

The app requests one Google permission (OAuth scope): https://www.googleapis.com/auth/youtube.upload. The developer grants it from the developer's own Google account. The app uses it only to upload videos that the app itself generated to that same account's YouTube channel. The app does not read the channel's videos, comments, subscribers, analytics, or any other account data.

What is collected, stored, and shared

  • The app does not collect personal information from anyone other than the developer.
  • The OAuth credentials of the developer's account are stored only as encrypted secrets in the developer's GitHub repository settings and are used only while the app runs.
  • No Google user data is sold, shared with third parties, used for advertising, or used to train machine-learning models.
  • This website does not use cookies or analytics.

Google API Services User Data Policy

The use and transfer of information received from Google APIs by yt-auto adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

The developer can revoke the app's access at any time at myaccount.google.com/permissions and delete the stored secrets from the GitHub repository settings.

Contact

Questions about this policy can be raised as an issue at github.com/wenzrosso/yt-auto/issues.
